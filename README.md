# example
example for hiddendevs
this example shows a script made by 1212hahahahh0 on rblx
this code works by using pathfindig service as a main service. 
it uses an ai the wanders around parts in a folder named "Waypoints" in workspace.
if the code suspects and entity close and that entity has a humanoid and is a player it uses it as a target and keeps on following them
when being followed it uses remote events connected to a client script to make the FOV slightly more to give off that panicked look.
if the player managed to get out of the distance where is being detected, the entity will stop following them and focus on the parts.
otherwise it uses a remote event and jumpscares the player, then taking this humanoid description then applying them on the entity itself, to give of the psychological horror feeling. like your identity got snatched.
this is basically it for this code. I hope you liked it! <3
